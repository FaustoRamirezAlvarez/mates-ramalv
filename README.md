# Nombre del Proyecto: Mateando

## Descripción:

Este proyecto es una página web básica desarrollada como parte de un curso de Front-End. La página está estructurada con HTML semántico y utiliza las etiquetas `<header>`, `<nav>`, `<main>`, `<section>`, y `<footer>` para organizar el contenido. 

El objetivo es aprender a crear la estructura básica de una página web y prepararla para futuras mejoras con CSS y JavaScript. En este caso, la temática elegida es un e-commerce orientado a un nicho clásico y muy popular en Argentina: **la venta de mates, bombillas y accesorios**.

### Pasos completados:
1. **Estructura básica (Ejercicio #1):** Se implementaron las etiquetas semánticas fundamentales, incluyendo un `<h1>` y un menú de navegación `<ul>` dentro de la etiqueta `<nav>`.
2. **Inserción de multimedia (Ejercicio #2):** Se incorporaron imágenes (incluyendo el logo en formato .png) y un video con atributos `controls` y subtítulos (`<track>`). Todos los recursos gráficos cuentan con su correspondiente atributo `alt` para accesibilidad.

### Archivos locales necesarios:
Para visualizar el proyecto completo sin enlaces rotos en el navegador, debes asegurarte de colocar en la misma carpeta que el archivo `index.html` los siguientes recursos:
- `logo.png`: El logotipo de la marca para el header.
- `mate_destacado.png`: Una imagen de muestra para la sección de productos.
- `video.mp4`: Un video corto (por ejemplo, cómo curar un mate).
- `subtitulos.vtt`: El archivo de subtítulos para el video.
